# PokeMil.github.io

Minimal static site for GitHub Pages.

How to publish:
1. Push these files to the root of the repository `PokeMil/PokeMil.github.io`.
   - GitHub Pages will automatically publish sites in repositories named `<username>.github.io` from the default branch.
2. (Optional) If you want a custom domain, create a `CNAME` file with your domain name.
3. (Optional) Add `.nojekyll` to disable Jekyll processing if you use directories starting with `_`.

Files:
- index.html — homepage
- about.html — about page
- projects.html — simple projects listing
- assets/css/style.css — styles
- README.md — this file

Need help customizing the theme, adding a blog, or switching to Jekyll/Hugo? Ask and I’ll scaffold that next.
